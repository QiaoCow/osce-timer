# OSCE 站位計時器（向日葵版）

給 OSCE 考官在考場使用的站位倒數計時器，單一 HTML 檔案，手機與大螢幕皆可使用。

中國醫藥大學附設醫院 教學部｜系統設計：陳巧錚

## 功能

- 每站倒數（預設 8 分鐘），剩 1 分鐘響鈴提醒，時間到全畫面轉紅並顯示超時秒數
- 向日葵微動態：倒數進度以 16 片花瓣呈現，隨時間逐片凋落
- 重設、下一位學員（學員代號自動遞增）
- 可設定站號、站名、每站時間、提醒時間與震動
- 計時中保持螢幕常亮
- 大螢幕模式：考場投影用的大字版面

## 使用方式

直接用瀏覽器開啟 `index.html`，或部署到 Vercel 等靜態網站服務。

- 第一次按「開始」後鈴聲才會啟用（瀏覽器限制）
- 手機切到靜音時鈴聲可能不響，請開啟音量或勾選震動

## 版本差異

| 功能 | 在 Claude 內開啟 | 獨立網址（本 repo、Vercel） |
| --- | --- | --- |
| 單機計時 | 可 | 可 |
| 大螢幕模式 | 可 | 可（由該裝置操作） |
| 全場同步 | 可（需登入 Claude） | 不提供 |
| 活動宣傳輪播 | 可 | 顯示預設歡迎訊息 |

同步與活動宣傳使用 Claude Artifact 的共享資料功能，獨立部署時會自動改為單機運作。

## 資料與隱私

本頁面不收集、不傳送任何資料。設定只存在使用者自己瀏覽器的本機儲存空間。範例資料（第 3 站 腹部身體檢查、學員 A）皆為假資料，請勿輸入真實學員個資。
